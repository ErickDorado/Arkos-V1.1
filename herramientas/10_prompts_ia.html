25 Prompts para Analistas de Datos

Listos para usar en Claude, ChatGPT o Grok · Personalizá las variables en naranja

Regla de oro: Nunca copies y pegues directamente el output de la IA sin revisarlo. Usá estos prompts para acelerar tu trabajo, pero siempre validá los resultados. La IA multiplica al analista que entiende el negocio; no reemplaza el criterio.

01
Query OTD por carrier y zona (con tendencia)
SQL
Sos un Senior Data Analyst especializado en logística. Escribí una query SQL optimizada para [DuckDB / PostgreSQL / BigQuery] que calcule el OTD (On-Time Delivery) por carrier y zona, incluyendo la tendencia mes a mes. La tabla se llama [nombre_tabla] y tiene las columnas: pedido_id, carrier, zona, fecha_entrega_real, fecha_entrega_prometida. Incluí comentarios explicando cada parte.
Cuándo usarlo: Al empezar el análisis de carriers. Reemplazá el motor de BD y los nombres de columnas con los reales de tu dataset.
02
Calcular CAC y LTV por canal de adquisición
SQL
Sos un analista de marketing. Escribí una query SQL en [motor] que calcule el CAC (Costo de Adquisición de Cliente) y el LTV estimado a 12 meses, agrupado por canal de adquisición. Tengo dos tablas: [tabla_inversión] (canal, mes, inversión_total) y [tabla_clientes] (cliente_id, canal_origen, fecha_primera_compra, ticket_promedio, frecuencia_compra_mensual). Mostrá también el ratio CAC/LTV.
Cuándo usarlo: Para analizar rentabilidad de canales de marketing. Esencial para el caso 2 del libro.
03
Detectar outliers en datos de ventas
SQL
Actuá como Senior Analyst de datos. Escribí una query SQL para detectar outliers en la columna [columna_monto] de la tabla [nombre_tabla] usando el método IQR (rango intercuartílico). Identificá cuáles filas son outliers, su porcentaje sobre el total y si podrían ser errores de carga o transacciones legítimas extraordinarias.
Cuándo usarlo: Antes de presentar cualquier análisis. Los outliers pueden distorsionar promedios y llevar a conclusiones incorrectas.

La tabla de pedidos se llama [tabla] con columnas: cliente_id, fecha_pedido. Motor: [motor].

13
Guía de EDA paso a paso para un dataset nuevo
EDA
Sos un analista de datos con experiencia en [industria]. Tengo un dataset nuevo de [describí brevemente el dataset: qué contiene, cuántas filas aproximadas, qué columnas principales]. EDA
